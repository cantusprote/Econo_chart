# Econo chart 월별 업데이트

Python 3.11+와 `openpyxl`, `pypdf`가 필요합니다. 프로젝트 전용 `.venv`에서 실행하며, 네트워크에서 월별 지표를 수집한 뒤 기존 서식을 유지하여 빈 월을 채웁니다.

## 최초 환경 구성

처음 한 번만 다음 스크립트를 실행합니다.

```bash
./setup_venv.command
```

이 스크립트는 `.venv`를 만들고 `requirements.txt`의 고정 버전 라이브러리를 설치한 뒤 `pip check`를 수행합니다. `.venv`가 없으면 UI와 업데이트 실행 스크립트가 환경 구성을 자동으로 시도합니다.

## 데스크톱 UI

Finder에서 `run_econo_ui.command`를 더블클릭하거나 터미널에서 다음을 실행합니다.

```bash
./run_econo_ui.command
```

좌측 상단 `update_general` 버튼은 `data/0_general.xlsx`를, `update_economic_state` 버튼은 `data/1.economic_state.xlsx`를, `update_gdp` 버튼은 `data/2.GDP.xlsx`를 갱신합니다. 세 기능은 실행 로그, 진행률 바, 중지 버튼을 공유하며 선택한 버튼에 맞춰 우측 표의 제공처와 수집 방식이 전환됩니다.

`Graph` 탭의 `1번 버튼`은 `data/0_general.xlsx`의 월별 KOSPI와 선행지수 순환변동치를 좌·우 이중축 선 그래프로 UI 내부에 표시합니다. 버튼을 누를 때마다 현재 통합문서를 다시 읽으며, Graph 1이 열린 상태에서 `update_general`이 끝나면 새로 추가된 월까지 자동으로 다시 그립니다.

`2번 버튼`은 같은 방식으로 월별 KOSPI를 좌축에, OECD 한국 선행지수를 우축에 표시합니다. Graph 2가 열린 상태에서 `update_general`이 끝나면 현재 통합문서의 최신 월까지 자동 갱신합니다.

`3번 버튼`은 월별 KOSPI를 좌축에, 일평균 수출액(억 달러)을 우축에 표시합니다. Graph 3도 버튼을 누를 때마다 현재 통합문서를 다시 읽고 `update_general` 완료 후 자동 갱신합니다.

3번 그래프의 `HP 수출평가` 하위 버튼은 `ln(KOSPI/일평균수출)` 비율을 월별 HP 필터(`λ=129,600`)로 추세와 순환변동으로 분리합니다. `100 × {exp[ln(KOSPI/일평균수출) - HP추세] - 1}`로 계산한 평가갭이 0보다 크면 수출 대비 고평가, 작으면 수출 대비 저평가로 표시합니다. 전체·최근 10년·최근 5년 선택을 지원하며, 양방향 HP 필터 특성상 새 데이터가 추가되면 최근 구간과 일부 과거 값이 수정될 수 있습니다.

`4번 버튼`은 월별 KOSPI를 좌축에, 국고채 3년 월평균 금리(%)를 우축에 표시합니다. Graph 4도 버튼을 누를 때마다 현재 통합문서를 다시 읽고 `update_general` 완료 후 자동 갱신합니다.

`5번 버튼`은 월별 KOSPI를 좌축에, 원·달러 월평균 환율을 우축에 표시합니다. 환율축은 데이터 범위에 맞춰 100원 단위로 자동 확장되며, Graph 5도 버튼 클릭 및 `update_general` 완료 시 최신 통합문서로 다시 그립니다.

`6번 버튼`은 `data/2.GDP.xlsx`의 KOSPI 연말 지수와 GDP 모델의 적정 KOSPI를 같은 축에 연간 선 그래프로 표시합니다. 버튼을 누를 때마다 현재 통합문서를 다시 읽으며, `update_gdp` 완료 후 자동으로 다시 그립니다.

6번 그래프를 열면 표시 기간 버튼 옆에 `명목GDP 예측치` 하위 버튼이 나타납니다. 이 버튼은 실행연도의 최신 국회예산정책처(NABO) 경제전망 보고서를 공식 사이트에서 검색하고 PDF의 명목 GDP·실질 GDP·GDP 디플레이터 전망을 읽습니다. `data/2.GDP.xlsx`의 직전연도 명목 GDP 실적에 최신 명목 성장률 전망을 적용해 예상 명목 GDP를 계산하며, 수집값·계산식·보고서 발표일·원문 링크를 화면에 함께 표시합니다. 결과는 공식 성장률을 이용한 프로그램 계산값이며 확정 GDP로 저장하지 않습니다.

`estimate_current_gdp` 하위 버튼은 실행일까지 발표된 한국은행 공식 RSS와 PDF를 다시 조회합니다. 국민소득 잠정치가 있는 분기는 명목 GDP 실적을 그대로 사용하고, 실질 GDP 속보만 나온 분기와 아직 발표되지 않은 분기는 최신 한국은행 연간 성장·물가 전망, 최근 GDP 디플레이터 실적, NABO 디플레이터 전망을 결합해 추정합니다. 화면에는 분기별 실적/추정 구분, 입력값, 계산식, 발표일, 원문 URL, 실적 반영 비율을 표시합니다.

`KOSPI 예측모형` 하위 버튼은 두 GDP 예측 시나리오를 세 회귀모형에 각각 대입해 연말 KOSPI를 계산합니다. GDP 단일 로그모형, GDP·10년 국채금리 모형, GDP 제곱항·금리 모형을 `data/2.GDP.xlsx`의 예측연도 이전 확정자료로 매번 재추정합니다. UI에는 모형별 예측값과 수식, 계수·표준오차, R²·조정 R², F값, SSR/SSE, 조건수 및 신뢰도 해설을 함께 표시합니다. 예측연도 12월 금리가 미확정이면 최신 확정 12월 금리를 대용값으로 명시하여 사용합니다.

각 그래프 상단의 `전체`, `최근 10년`, `최근 5년` 버튼으로 표시 기간을 바꿀 수 있습니다. 최근 기간은 프로그램 실행일이 속한 달을 기준으로 각각 과거 120개월과 60개월의 달력 범위를 사용합니다. 해당 기간에 발표된 데이터가 40개월뿐이면 40개월만 오류 없이 표시하며, 선택한 기간은 다른 그래프로 전환하거나 `update_general` 완료 후 자동 갱신할 때도 유지됩니다.

Graph 6의 최근 10년·5년은 같은 원칙을 연 단위로 적용하여 프로그램 실행연도를 포함한 최근 10개년·5개년 범위를 사용합니다. 해당 범위에 발표된 연간 자료가 더 적으면 존재하는 연도만 오류 없이 표시합니다.

## 실행

2026년 3월 단월 검증:

```bash
.venv/bin/python update_2026_03.py
```

프로젝트 `data/0_general.xlsx`를 직전 완료 월까지 직접 갱신:

```bash
./run_update.command
```

종료 월을 직접 지정하려면:

```bash
./run_update.command --through 2026-07
```

`data/0_general.xlsx`가 처음부터 없을 때만 `temp.xlsx`를 초기본으로 한 번 복사합니다. 이후에는 새 XLSX를 만들지 않고 `data/0_general.xlsx`만 계속 갱신합니다. 기본적으로 직전 달까지 확인하며, 월 전체가 아니라 빈 지표별로 수집을 시도합니다. 발표된 값은 즉시 해당 빈 셀에 저장하고 미발표 값은 `PENDING`으로 남긴 채 다른 지표와 다음 월을 계속 처리합니다. 이후 실행할 때마다 남은 빈 셀만 다시 확인하며 이미 채워진 값은 덮어쓰지 않습니다.

## 경제상태 파일 업데이트

`data/1.economic_state.xlsx`의 KOSPI, 선행지수 순환변동치, OECD 한국 선행지수, 제조업 재고율을 실행일 기준 직전 완료 월까지 갱신합니다.

```bash
./run_economic_state_update.command
```

종료 월을 지정하려면 다음처럼 실행합니다.

```bash
./run_economic_state_update.command --through 2026-06
```

4개 지표 중 하나라도 비어 있는 월을 대상으로 하며, 발표된 지표는 즉시 해당 빈 셀에 저장합니다. 미발표 지표는 `PENDING`으로 남기고 다른 지표와 다음 월 수집을 계속하며, 다음 실행 때 남은 빈 셀만 다시 확인합니다. 기존 값은 보존되어 덮어쓰지 않습니다.

## 연간 명목 GDP 업데이트

`data/2.GDP.xlsx`의 B열은 한국은행 국민계정의 원화 명목 GDP를 조 원 단위로 저장합니다. 2022년 자료는 다음처럼 업데이트합니다.

```bash
.venv/bin/python update_gdp_2022.py
```

스크립트는 명목 GDP, KOSPI 연말 종가, 국고채 10년 12월 평균금리를 수집하고 적정 KOSPI·평가율·회귀용 로그 변수를 기존 모델과 같은 방식으로 계산합니다. 기존 연도가 없으면 직전 행의 서식을 복사해 새 행을 만들며, 이미 채워진 셀은 `--force` 없이는 덮어쓰지 않습니다. `--dry-run`으로 조회만 할 수도 있습니다.

실행일 기준 직전 완료 연도까지 모든 빈 연도를 자동으로 갱신하려면 다음 일반화 스크립트를 사용합니다.

```bash
.venv/bin/python update_gdp.py
```

각 연도의 세 원자료를 독립적으로 수집하므로 하나가 미발표이거나 일시적으로 실패해도 나머지 값은 저장합니다. 빈 항목은 다음 실행 때 다시 확인합니다. `--through 2024`, `--from-year 2023`, `--dry-run` 옵션을 지원합니다.
